# invisi-sdk-protocol

Version `1.2.3`. Pure public contract ABI, strict wire codecs and DTOs, circuit statements/identities, Source digests, recognized trees and gas reference catalogs. Depends only on primitives among SDK modules; no network or proof engine.

See the [workspace documentation](https://github.com/invisi-labs/invisi-sdk-rust) for usage. Licensed under Apache-2.0.
